# project-Khaneichuk
   # Консультації онлайн
   Вебзастосунок для онлайн-запису студентів на консультації викладачів.
   Дозволяє викладачам формувати графік консультацій, а студентам — переглядати
   вільний час і записуватися через вебінтерфейс.

   Ролі: студент, викладач, адміністратор.
   Документація: каталог docs/
